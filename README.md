# Hyrox 27

Web app d'entraînement pour Hyrox Toulouse (février 2027) : plan de 12 semaines, minuteurs avec bips écran verrouillé, suivi des séances et de la progression. Les données restent sur le téléphone.

Installation sur iPhone : ouvrir le site dans Safari, puis Partager → Sur l'écran d'accueil.
